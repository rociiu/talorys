Get started

Deploy in minutes

Get your own instance of Talorys running on Cloudflare with a single command.

View detailed installation guide →
  1. 1

    Prepare your environment

    Create a free Cloudflare account and install Node.js 22 or newer.

  2. 2

    Run one command

    npx create-talorys@latest
  3. 3

    Start using Talorys

    Sign in to Cloudflare, choose an owner password, and open the pages.dev URL the installer prints.

FAQ

Frequently asked questions

View troubleshooting →

Is Talorys really free?

Talorys is open source and free. It's designed to fit Cloudflare's free plans, which have daily quotas, and it never turns on paid features by itself.

Do I need technical knowledge?

Not much. You need a Cloudflare account and Node.js 22+. One command does the install, and running it again safely picks up where it left off.

Where does my data go?

Your data lives in your Cloudflare account. There's no Talorys-hosted backend, and we don't collect any telemetry.

Can I use it on mobile?

Yes. Talorys works in modern mobile browsers. On iPhone and iPad, add it to your Home Screen to get push notifications.
